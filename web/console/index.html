Nodos de infraestructura

Enrollment pendiente
El registro remoto de nodos permanece deshabilitado hasta completar autenticación mutua TLS, autorización, revocación y persistencia de heartbeats. Esta consola no acepta certificados ni secretos de nodos.

Preparar un Node Agent

En el equipo que ejecutará el agente, puedes generar el inventario local con:

cargo run -p cloudforge-node-agent

Para revisar la configuración de identidad:

cargo run -p cloudforge-node-agent -- --check-identity

El segundo comando solo valida configuración local; no registra el nodo ni demuestra una conexión autenticada.
